# VisonLab
![Version](https://img.shields.io/badge/version-v1.0-00D4FF)
![Status](https://img.shields.io/badge/status-early%20development-orange)


A python-based real-time computer vision application built with **PySide6** and **OpenCV**.

VisionLab provides a desktop GUI for accessing a webcam and applying basic real-time image-processing techniques.
